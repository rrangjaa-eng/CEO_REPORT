# 계산 핵심(3단계) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. 단계는 체크박스(`- [ ]`)로 추적.

**Goal:** 지금 파이썬의 `data.load`(입력 폴더 읽기)와 `calc.compute`(주간·월간 보고 숫자 R)를 타입스크립트로 옮겨, 정답 예시(golden/cases 46개)의 `weekly.json`·`monthly.json` 과 1원·1글자까지 같게 만든다.

**Architecture:** 브라우저 안에서 도는 순수 함수. `web/src/model/`은 파일(이름→글) 묶음을 받아 표준 자료 `Data`로 바꾸고(`data.load` 대응), `web/src/calc/`는 `Data`에서 `R`을 만든다(`calc.compute` 대응, 절마다 파일 하나). 파일 시스템·DOM·네트워크를 쓰지 않는다. 시험은 golden 사례를 읽어 비교한다.

**Tech Stack:** TypeScript 5.9 (strict, noUncheckedIndexedAccess), Vitest 3.2. 새 의존성 없음.

**Spec:** CEO_REPORT 개발 계획 3단계(https://claude.ai/artifact/B9415mJgnLuPGuCKD1dGuM), `golden/RULES.md`(규칙 41개 + '새 시스템에서 바꿀 것' 7건). 정답지는 파이썬 원본: `ceo_report/data.py`, `ceo_report/calc.py`, `ceo_report/fundplan.py`(apply 부분), `ceo_report/tax.py`(merge), `ceo_report/debts.py`(compare), `ceo_report/gate.py`, `ceo_report/util.py`, `ceo_report/wehago.py`(norm_code·norm_vendor).

## Global Constraints

- 폴더: `web/src/model/`, `web/src/calc/`, `web/tests/calc/` 만 만든다. `web/src/collect`, `server`, `extension`, workflows, `web/package.json`, `tsconfig` 는 건드리지 않는다(2단계 스레드와 합의).
- golden/ 은 읽기만 한다. 파이썬 코드도 읽기만 한다.
- 날짜는 `"YYYY-MM-DD"` 문자열(`IsoDate`)로 다룬다. 시간대에 따라 바뀌는 `new Date()` 지역 시간 계산 금지(UTC 기준 함수만).
- 금액은 정수 number. 파이썬 `round()`는 은행가 반올림, `int()`는 0 쪽 버림, `//` 는 내림 — 똑같이 옮긴다. 파이썬 문자열 포맷(`"{:,}"`, `%s`, `%d`)도 같은 글자를 내야 한다.
- 결과 객체의 키 이름은 파이썬 R 의 키 그대로(영문 snake_case·한글). 목록 순서도 파이썬과 같게(정렬은 안정 정렬).
- 모르는 값은 0이 아니라 `null`(U1). '오늘'은 쓰지 않고 늘 `asof` 인자로.
- 연도를 새로 코드에 고정하지 않는다. 단 U8 결정대로 `PRIOR_LAST_YEAR=2025` 는 지금처럼 둔다(이름 붙인 상수 하나).
- 기대값과 달라도 되는 것은 RULES.md '새 시스템에서 바꿀 것' 7건뿐. 계산 범위에 드는 것은 F6·F9·F12·U6·U10(D7은 변환, U8은 그대로).

## Review Focus

1. 금액이 비거나 글자인 칸 → 0이 아니라 미확인(null)과 건수로 남는지(U1). 각 절 시험에 `u_unknown_not_zero` 비교 포함.
2. 해 바뀜(12/31~1/2)·윤년 2월·월말 31일 더하기 → 날짜 함수 단위 시험(`dates.test.ts`)에 2027-12-31, 2028-02-29 포함.
3. 시간대: 한국 PC(UTC+9)에서 날짜가 하루 밀리지 않는지 → `TZ=Asia/Seoul` 로도 시험 실행.
4. 파이썬 반올림 차이(0.5) → `pyRound` 단위 시험(2.5→2, 3.5→4, -2.5→-2).
5. 자료 파일 없음·열 없음 → 멈추지 않고 파이썬과 같은 issues 문구·`out_missing`/`in_missing`.

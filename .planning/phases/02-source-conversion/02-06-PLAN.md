## Interface contract

- `XCHK_FILE = "위하고대조.csv"`, `XCHK_COLUMNS = ["구분", "대상", "이름", "항목", "금액", "건수", "비고"]` — one fact per row
  (long format): the CSV stores facts only; differences are derived by load_xchk.
- `build_xchk(books, costs, revenue, projects, requests, match, project_rows, meta)` — costs / revenue: linking results;
  projects: linking.projects_of; requests: linking.requests_of (all statuses); match: wehago.match_requests(books,
  requests); project_rows: rows (dicts with 프로젝트번호 and 계약금액 text) of the 프로젝트.csv Table built in the same run
  (plan 02-07 passes them; tests pass literal dicts); meta: OrderedDict of 기준 facts ('장부 기준일', '분개장',
  '매입매출장', '전자세금계산서(매입)', '인트라넷 스냅숏', '변환 시각'). Returns Table(XCHK_FILE, XCHK_COLUMNS, rows,
  checks, notes). Pure: no file access.
- `load_xchk(input_dir)` → `{"state": 'ok' | '자료 없음' | '읽을 수 없음', "reason", "meta", "status", "projects",
  "outside", "unlinked", "unlinked_lines", "vendors", "vendor_summary", "revenue", "revenue_unlinked",
  "revenue_unlinked_lines", "totals"}`; reads with util.read_csv-style UTF-8-BOM handling, never raises.

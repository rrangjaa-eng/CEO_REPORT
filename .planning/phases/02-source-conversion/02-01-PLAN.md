## Interface contract (plans 02-03 .. 02-07 use these names)

- `convert.GENERATED`, `convert.MANUAL` — PATTERNS §2.
- `convert.Check`, `convert.check_result`, `convert.Table`, `convert.cell_amount`, `convert.cell_date`,
  `convert.write_table` — PATTERNS §3.1.
- `convert.read_config(input_dir) -> (cfg, notes)` — PATTERNS §3.2. cfg values: tuples of strings for code lists,
  str for marks, int for link_days, tuple of str for closing_sorts and card_words.
- `convert.read_prev(input_dir, name) -> list[dict]` — previous rows of a generated CSV as raw text dicts
  (util.read_csv with that file's SCHEMA columns, own Issues object, `_line`/`_file` keys removed); [] when absent or
  unreadable.
- `convert.run(input_dir, collect_dir, wehago_dir, asof, now, stamp=None) -> Result` where Result has `code` (int),
  `lines` (list of str for stdout), `tables` (list of Table), `backup` (path or None). `stamp` overrides the backup
  folder time (tests). run never raises for books, snapshot or file problems.
- `convert_pl.build_pl(books, cfg, prev_rows, links=None) -> Table` — this plan fills only 회사 rows; `links` is the
  hook plan 02-03 uses for 팀·프로젝트 rows (None here).
- `wehago.load_books(folder, asof, stale_days)`: `stale_days=None` skips the age check only. A book whose ref date
  cannot be known is still '경과' with its reason. 분개장 rows gain `sort` (구분 text, masked). Nothing else changes.

## Planner decisions (Claude's discretion, recorded for the verifier)

- P1-1 (D-43 '옮긴다'): old files are COPIED to 입력/이전/<stamp>/ first, then the new file is written to a temp name in
  입력/ and `os.replace`d onto the target. End state equals "moved then written", and a crash never leaves 입력/ without
  the file. Before any copy or replace, every existing target is opened with 'r+b' and closed; any OSError there →
  exit 7, nothing touched.
- P1-2 (D-40 rows): 손익.csv WEHAGO rows are rebuilt each run; rows whose 출처 is not 'WEHAGO' in the previous
  손익.csv (e.g. 인트라넷완료보고, PL-02) are carried over unchanged after the WEHAGO rows, because conversion
  cannot produce them. 변환결과 line: '알림 이전 손익.csv의 WEHAGO 외 출처 줄 N건 그대로 옮김'.
- P1-3 (D-40 months): months = every YYYY-MM that has at least one dated 분개장 line (any account). A month with no
  line of a category gets 0 (the books cover that month). A category line with neither 차변 nor 대변 makes that
  month's cell '' and adds '알림 금액 없는 손익 줄 N건 (YYYY-MM <category>) → 그 달 칸 비움'. Undated category lines
  go to no month and are listed '알림 날짜 없는 손익 줄 N건 <won>'. Lines dated after the 장부 기준일 are kept in their
  month (counted in the WEHAGO line as '장부 기준일 이후 전표 N건').
- P1-4 (D-39 classification, by 계정 Code = the first 'Code' column): 매출 = code in revenue_codes, amount 대변−차변;
  직접비 = 5-digit code starting with a direct prefix AND 계정과목 (whitespace removed) containing direct_mark, amount
  차변−대변 (same rule as W-10 / D-16); 공통비 = 5-digit code starting with a common prefix, amount 차변−대변 (lines
  without common_mark are counted and listed). Other codes starting with 4..9 → '손익.csv에 넣지 않은 손익 계정' with
  code, name, line count and 차변−대변 sum. Codes starting with 1..3 are balance-sheet lines and are ignored.
- P1-5 (Q-3 default): a year is closed when the 분개장 has a line dated in that year whose `sort` (whitespace removed)
  is in closing_sorts; months of closed years get 잠정 '', all others 'Y'.
- P1-6 (age): conversion uses `stale_days=None`; the WEHAGO header line in 변환결과.txt adds
  '· 기준일보다 N일 이전' when the 장부 기준일 is before the 기준일 (no stop).
- P1-7: 입력/ is created when missing (the folder only; manual files are then reported missing in 변환결과 by name).

## Planner decisions (wiring)

- W-1 run order: config → books (not ok → exit 3, unchanged) → snapshot → requests / projects → links → match =
  wehago.match_requests(books, requests) (only with a snapshot) → read_prev for every generated CSV (before anything is
  backed up) → sales = wehago.load_sales(wehago_dir, asof, books) → bank = {"balances": rows of 계좌잔액.csv, 
  "transactions": rows of 입출금내역.csv} read with util.read_csv and data.SCHEMA columns (None when missing; never
  written, D-48) → Tables: 손익 (build_pl), 계산서 (build_invoices), and with a snapshot 프로젝트 (build_projects),
  프로젝트집행 (build_execs), 위하고대조 (build_xchk with the 프로젝트 Table rows, meta, cfg and bank) → cross-file Checks →
  step A: one all-or-nothing write of the CSV Tables (02-01 path) → data.load listing on the replaced folder (W-6) →
  step B: 변환결과.txt through the same safe path. A failure in step A replaces nothing (exit 7); a failure in step B
  keeps the new CSVs, prints the error and exits 7.
- W-2 no snapshot: 프로젝트 / 프로젝트집행 / 위하고대조 are Table(written=False, reason '인트라넷 스냅숏 없음 (기존 파일
  그대로)'); the write path neither backs them up nor touches them.
- W-3 no usable sales file (D-46): 계산서 is Table(written=False) and is not touched. Line: when 입력/계산서.csv exists,
  '[계산서.csv] 만들지 않음 — <prefix> → 기존 계산서.csv 유지 (갱신 안 됨, 작성일 <YYYY-MM-DD>)' with prefix '매출 계산서 엑셀
  없음' for state '자료 없음' and the load_sales reason otherwise (작성일 = local date of os.path.getmtime); when it does
  not exist, '[계산서.csv] 만들지 않음 — 자료 없음 (매출 계산서 엑셀)' (plus the lookalike hint).
- W-4 cross-file Checks (section '[파일 사이 대조]', counted in '대조 불일치'): csv side of 손익's 직접비 Check vs csv side
  of 프로젝트집행's '원가 줄 합계' Check vs 위하고대조 'WEHAGO 원가' + 미연결원가; 손익 매출 vs 위하고대조 'WEHAGO 매출' +
  매출미연결; Σ 손익 '프로젝트 미연결' 직접비 vs 위하고대조 미연결원가 vs Σ extra['cost_portions'] of 프로젝트집행 WEHAGO rows
  whose 프로젝트번호 is not a 프로젝트.csv key. Only Checks whose files were both written run. The Table checks of every
  builder (including 02-04's B3 snapshot money lines) are printed under their file's section.
- W-5 자금일정 overlap: read 입력/자금일정.csv read-only; list pairs per truth 7; count line always printed.
- W-6 data.load listing: after the CSV replace, data.load(input_dir) issues as '  확인 <file> <line>번째 줄: <message>'
  (masked), count line '보고서 입력 확인 필요 N건'. Manual files that still use other project numbers (the sample uses
  'P26201'; generated files use '26201') appear here — the intended signal.

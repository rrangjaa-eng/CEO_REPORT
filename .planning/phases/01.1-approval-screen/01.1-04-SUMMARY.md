- **Found during:** Task 3 RED

- **Fix:** `browser_dom` loads the page in an iframe of exactly 390 px (srcdoc, same origin) when the requested width is below 500, and the test asserts `innerWidth == 390` inside it; the 1280 run uses the real `--window-size=1280,900` and asserts `innerWidth == 1280`. Layout and media queries evaluate against the iframe viewport.
- **Files modified:** tests/test_approval.py
- **Commit:** f692063

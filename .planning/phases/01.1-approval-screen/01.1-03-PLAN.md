## Phase Goal

ROADMAP Phase 01.1 goal (verbatim): "지급 요청이 들어올 때마다 더블클릭 한 번으로, 승인 대기 요청을 체크로 넣고 빼며 앞으로 8주 주별 잔액·최저점·부족 주를 바로 본다. 인트라넷(intranet.plant8.co.kr)은 로컬 수집기가 허용 경로만 읽는다(/confirm 등 쓰기 경로 차단)."

This plan delivers "더블클릭 한 번으로" by joining plan 01.1-02's collector to plan 01.1-01's snapshot and screen:
- 실행_승인검토.bat → ID/비밀번호 prompt → collection of every page → snapshot on disk → screen in the browser.

It also adds a 구조 점검 mode for the first real run on the user's PC. The cloud cannot log in to the intranet, so that run is the human acceptance step. It checks login, headers and paging against the real site and writes nothing.

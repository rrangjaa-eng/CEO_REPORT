## Accomplishments

- `check_url(method, url)` returns the URL without fragment or raises `BlockedRequest` (message: method, path, reason; never query values or userinfo). It rejects other methods, hosts, http, ports, userinfo, `%`/backslash/`//`/`..`/`;` paths, deny words (confirm, logout, delete, del, remove, save, insert, update, modify, write, edit, drop, approve, reject, cancel; 삭제/저장/수정/승인/반려), unknown or non-numeric query values, and `/project/payment` without exactly `pro_num=<digits>`.
- `make_opener` builds the `OpenerDirector` by hand: `AllowlistGuard` (order 100, https and http `_request`), `ProxyHandler`, the transport or `HTTPSHandler(context=ssl.create_default_context())`, `HTTPCookieProcessor` over a plain in-memory `CookieJar`, `CheckedRedirectHandler` (max 5, login POST never followed), error handlers. A 302 to `/confirm/...`, another host or http raises `BlockedRequest` with the transport called once.
- `collect` follows numbered and `>` page links (query page names or a trailing `/<digits>`) with a FIFO queue and canonical-URL dedupe, de-duplicates by 번호, skips Total rows, keeps `pro_num` from the `/project/payment` link without requesting it, waits `delay` between requests, and reports progress.

## Interpretation notes (not deviations)

- A link such as `?page=1` points at the page already being read (page=1, an absent page name and a trailing `/0` count as the first page), so it is recognised but not fetched. Without this the plan's 3-page fixture would need 4 requests and `payment_pages == 3` could not hold.
- Single-cell rows (a colspan notice such as 등록된 자료가 없습니다), all-blank rows and Total/합계/총계 rows in the first two cells are not data rows. A list with only such rows stops with the '0건' message.
- `make_opener(proxies=None)` uses the system proxy settings as planned. When a proxy variable is set, `ProxyHandler` itself exposes `https_open` (and `http_open` for an http proxy); it hands https requests to the verified `HTTPSHandler` (CONNECT tunnel, certificate and host name still checked) and the guard blocks plain http first. The transport-safety tests therefore check the other handlers, plus the strict case with `proxies={}`.
- `calls_made` is an integer count of requests sent through the opener.
- Progress callback receives `(label, page_number, cumulative_distinct_rows)` with labels `지급요청` and `프로젝트`; plan 03's '누계' line matches.

### `ceo_report/approval.py` (service, transform)

**Analog:** `ceo_report/calc.py` lines 311-428. To add the intranet requests, append new events in the same dict shape. Do NOT edit `compute()`: existing 118 tests must keep passing. If a shared helper is wanted, extract it without behavior change and run the full suite.

```python
                       "firm": e["firm"] and e["state"] == "요청미지급", ... "source": "프로젝트집행", "vat_unknown": e["vat"] is None})
```
A-3 double counting: intranet snapshot is the basis for project payment requests. Drop `source == "프로젝트집행"` events of state 요청미지급 (or matching project and amount) when a snapshot exists.

**Classification of events** (calc.py 352-368): `amount None` -> `amount_unknown`; `date None` -> `undated`; `date <= asof` -> `past`; beyond horizon -> `beyond`. Never summed. Replace the 4 week + month buckets with N Monday-start weeks (`승인검토_주수`):
```python
undated, past, beyond, amount_unknown = [], [], [], []
for ev in events:
    if ev["amount"] is None: amount_unknown.append(ev); continue
    if ev["date"] is None: undated.append(ev); continue
    if ev["date"] <= asof: past.append(ev); continue
    if ev["date"] > horizon: beyond.append(ev); continue
    for b in buckets:
        if b["from"] <= ev["date"] <= b["to"]:
            b[("in_" if ev["io"] == "in" else "out_") + ("firm" if ev["firm"] else "est")] += ev["amount"]; break
```

**Start balance None never 0** (calc.py 370-378):
```python
start_cash = R["s1"]["available"]
bal_f = bal_a = start_cash
for b in buckets:
    if start_cash is None:
        b["bal_firm"] = b["bal_all"] = None  # 시작 잔액을 모르면 0에서 시작해 계산하지 않는다
        continue
    bal_f += b["in_firm"] - b["out_firm"]
    bal_a += b["in_firm"] + b["in_est"] - b["out_firm"] - b["out_est"]
```
D-24 differs: baseline = firm inflows + ALL outflows (firm+est); show est inflows separately. Do not copy `bal_firm` (which drops est outflows) literally.

**Daily min balance** (calc.py 379-397): `defaultdict(int)` per date, sorted days, track `low, low_d`. Starts with `low, low_d = bal, asof`. Reuse for weekly intra-week min (D-22) and per-request "min if removed" (D-21: recompute the min with that event excluded, in Python for the table and mirrored in JS).

**Unknown-handling counts** (calc.py 399-412, uses `ssum`):
```python
total, unknown = ssum(ev["amount"] for ev in evs)
past_sum[io] = (None if evs and unknown == len(evs) else total, len(evs), unknown)
```
Use `ssum_or_none` from util.py (lines 152-156) for the same behavior. D-04: undated and amount-unknown are shown as N cases + confirmed amount, never in the weekly graph.

**Settings parse with visible default (R4)** (calc.py 54-86). Add new keys to a settings-num loop; blank/invalid falls back to default AND adds an Issue:

For `승인검토_주수` require an int >= 1 (like 표시수 check). `승인검토_정기지출` is text (comma list), use `d.settings.get` + split; blank means default. `위험_최소보유현금` already exists via `R["settings_num"]`. ## Shared Patterns

### Unknown is never zero
**Source:** `ceo_report/util.py` lines 89-104 (`num`), 141-156 (`ssum`, `ssum_or_none`), 159-170 (`won`, `man` print "미확인" for None).
**Apply to:** approval.py, intranet.py (amount parse), renderer.
```python
def ssum_or_none(values):
    vals = list(values); total, unknown = ssum(vals)
    return (None if vals and unknown == len(vals) else total), unknown
```
Always display `confirmed total + unknown N cases`.

### Input-check list (Issues)
**Source:** `ceo_report/util.py` 13-20 and `ceo_report/calc.py` 47-49, 82-86. `Issues.add(file, line, msg)`; copy `d.issues.items` before adding so Data is not mutated.

### Settings default with visible notice (R4)
**Source:** `ceo_report/calc.py` 54-86 plus `util.setting_num` (107-119, returns `(default, reason)` with reasons "설정 비어 있음" / "숫자 아님").

### Encoding
CSV read: UTF-8-sig then CP949 (`util.read_csv`). CSV write: `encoding="utf-8-sig", newline=""`. HTML write: `encoding="utf-8"`. Stdout is Korean, relies on `chcp 65001` in the launcher.

### Python compatibility
Python 3.8+ stdlib only (D-15): no `match`, no `X | Y` type unions, no `str.removeprefix`, no `dict | dict`, no `list[int]` annotations at runtime. Existing code uses `%`-formatting and `"{:,}".format`; follow that style.

### Output location
`출력/` folder is gitignored; `os.makedirs(a.출력, exist_ok=True)`.
